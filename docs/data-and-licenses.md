# データ出典とライセンス

第三者データのライセンスはアプリケーションコードのライセンスとは別です。データを静的アセットとして再配布・変換・キャッシュする前に、各公式配布元の最新版の条件を確認し、取得日時とバージョンを記録します。

## EJDict

日本語訳の辞書データとして利用します。EJDict の公式リポジトリは [`kujirahand/EJDict`](https://github.com/kujirahand/EJDict) で、ライセンスは CC0 1.0 Universal です。`public/data/lookup/` の静的アセットへ変換して配布します。

## Tatoeba

例文データとして利用します。Tatoeba のデータは CC BY 2.0 FR です。静的アセットには例文ごとの Tatoeba sentence ID と元 URL を保持し、アプリ内の出典リンクから確認できるようにします。EJCSV の英語文エクスポートには作者名が含まれないため、データセット全体の帰属表示もフッターと本ページで維持します。例文の翻訳を利用する場合は、翻訳者の帰属条件も確認します。

## Web Speech API

英単語・例文の読み上げには、ブラウザが提供するWeb Speech APIを利用します。アプリケーションは音声モデルや音声ファイルを配布・保存しません。実際に利用される音声合成エンジン、音声データ、利用条件は端末・OS・ブラウザの提供元に従います。

## アプリケーションで利用するOSS

間隔反復の計算には `ts-fsrs` を利用しています。`ts-fsrs` はMITライセンスで、著作権者は Open Spaced Repetition です。その他の直接依存パッケージもMITライセンスです。著作権表示、公式リポジトリおよび各ライセンスへのリンクはアプリ内の [`/licenses`](../app/licenses/page.tsx) に表示します。

対象パッケージとバージョンは `package-lock.json` を正とします。依存パッケージを更新した場合は、著作権者・ライセンス・表示内容を再確認してください。開発専用の推移依存パッケージについても、配布物を作成する際は各パッケージのライセンスファイルを保持します。

## 実装ルール

- 出典情報をカードから失わない。
- データベースの seed/import にライセンス情報と取得日を添える。
- ライセンスが確認できないデータを本番データへ混ぜない。
- 帰属表示を UI から削除できないようにする。
- `docs/` の記載は法的助言ではない。公開前にライセンス本文を確認する。
