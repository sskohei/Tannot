# データ出典とライセンス

第三者データのライセンスはアプリケーションコードのライセンスとは別です。データを再配布・変換・キャッシュする前に、各公式配布元の最新版の条件を確認し、取得日時とバージョンを記録します。

## EJDict

日本語訳の辞書データとして利用します。計画上のライセンスは CC0 です。配布物に含める場合も、出典名・取得元・データの版を表示できるようにします。

## Tatoeba

例文データとして利用します。計画上のライセンスは CC BY 2.0 FR です。例文ごとに Tatoeba の出典 ID、作者、元 URL または帰属に必要な情報を保持し、アプリ内の「出典」またはライセンスページから確認できるようにします。例文の翻訳を利用する場合は、翻訳者の帰属条件も確認します。

## Kokoro-82M

英単語・例文音声の生成に利用します。モデル、重み、依存ライブラリのライセンスと商用利用条件は導入時に公式情報で確認し、モデル名とライセンスを公開ページに記載します。生成音声の利用条件がモデル以外の音声・推論基盤にも依存する場合は、その条件も明記します。

## 実装ルール

- 出典情報をカードから失わない。
- データベースの seed/import にライセンス情報と取得日を添える。
- ライセンスが確認できないデータを本番データへ混ぜない。
- 帰属表示を UI から削除できないようにする。
- `docs/` の記載は法的助言ではない。公開前にライセンス本文を確認する。
