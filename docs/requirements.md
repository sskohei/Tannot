# 要件定義

## MVP の範囲

### 単語帳作成

- Google でログインできる。
- 改行区切りまたはカンマ区切りの英単語・熟語を入力できる。
- 前後空白を除去し、空行・重複を整理する。
- 各入力について日本語訳、英語例文、再生操作を提供する。音声URLや音声ファイルは保存しない。
- 辞書・例文が見つからない項目はエラー理由を示し、単語帳全体の作成を失敗させない。
- 単語帳名を付けて保存できる。

### 学習

- 今日が復習日のカードを、優先度順に出す。
- 表面には英単語と英単語音声、解答後には日本語訳・例文・例文音声を表示する。
- 「もう一度」「難しい」「普通」「簡単」で評価し、次回復習日を更新する。
- 学習途中で再読み込みしても、確定済みの評価は二重適用されない。

### アカウント・課金

- ログイン、ログアウト、セッション維持を提供する。
- 無料利用枠と有料プランの判定はサーバー側で行う。
- Stripe Checkout と webhook によって契約状態を同期する。

## 非機能要件

- 他ユーザーの単語帳・カード・学習記録を参照、変更できない。
- API は不正な入力に 4xx、サーバー障害に 5xx を返し、クライアントへ秘密情報を返さない。
- 音声生成に失敗しても、テキストによる単語帳作成・学習は継続できる。音声は再生操作時にKokoroで生成する。
- データソースの帰属情報をアプリ内または文書ページから確認できる。

## 将来候補

発音記号、例文の日本語訳、タグ・検索、学習統計、CSV 入出力、モバイル最適化、音声キャッシュや事前生成。
