# 要件定義

## MVP の範囲

### 単語帳作成

- Google でログインできる。
- 改行区切りまたはカンマ区切りの英単語・熟語を入力できる。
- 前後空白を除去し、空行・重複を整理する。
- 各入力について日本語訳、英語例文、Web Speech APIによる再生操作を提供する。音声URLや音声ファイルは保存しない。
- 辞書・例文が見つからない項目はエラー理由を示し、単語帳全体の作成を失敗させない。
- 単語帳名を付けて保存できる。

### 学習

- 今日が復習日のカードを、優先度順に出す。
- 表面には英単語と英単語音声、解答後には日本語訳・例文・例文音声を表示する。
- 「もう一度」「難しい」「普通」「簡単」で評価し、次回復習日を更新する。
- 学習途中で再読み込みしても、確定済みの評価は二重適用されない。
- 今日の復習件数を単語帳ごとに確認できる。

### 単語帳の管理

- 単語帳名を変更できる。
- 単語、訳または例文からカードを検索できる。
- カードの英単語・熟語、訳、例文を編集できる。
- カード単位で削除でき、対応する学習履歴も削除される。
- 単語帳をフォルダで整理し、並び順を変更できる。
- カードにタグを付け、複数カードへのタグ追加・一括削除ができる。
- CSVで単語帳を取り込み、カードを出力できる。

### アカウント・課金

- ログイン、ログアウト、セッション維持を提供する。
- 無料プランでは単語帳を3冊まで、各単語帳のカードを100枚まで作成できる。利用枠と有料プランの判定はサーバー側で行う。
- プレミアムは月額500円（税込）、7日間無料トライアル、自動更新とする。プレミアム中は単語帳とカードの作成数を無制限にする。
- Stripe Checkout と webhook によって契約状態を同期し、Stripe Customer Portalで支払い方法、請求書、解約を管理できる。
- 設定画面からデータエクスポートを提供し、有効なプレミアム契約がない利用者はアカウントを削除できる。
- プレミアムでは学習統計、1日の新規／復習上限、出題順、ブラウザ通知リマインダーを提供する。

## 非機能要件

- 他ユーザーの単語帳・カード・学習記録を参照、変更できない。
- API は不正な入力に 4xx、サーバー障害に 5xx を返し、クライアントへ秘密情報を返さない。
- 音声読み上げに失敗しても、テキストによる単語帳作成・学習は継続できる。音声は再生操作時にブラウザのWeb Speech APIで処理する。
- データソースの帰属情報をアプリ内または文書ページから確認できる。
- 購入前に料金、無料トライアル、自動更新、解約および返金の条件を確認できる。利用規約、プライバシーポリシー、特定商取引法に基づく表記を常設リンクで提供する。
- プレミアム申込み時に13歳以上であること、および18歳未満の場合は保護者の同意を得ていることを確認する。
- 購入時に同意した利用規約・プライバシーポリシーの版を保存する。
