# 学習アルゴリズム

MVP では Anki に似た間隔反復を採用します。カードごとに `due_at`、`interval_days`、`ease_factor`、`repetitions` を保存します。

## 評価

| UI | 意味 | 初期動作の目安 |
| --- | --- | --- |
| もう一度 | 想起できなかった | 近い時刻に再提示、間隔をリセットまたは縮小 |
| 難しい | 苦労して想起 | 現在間隔を小さく延長 |
| 普通 | 妥当に想起 | 現在間隔を標準倍率で延長 |
| 簡単 | 余裕を持って想起 | 現在間隔を大きく延長 |

具体的な倍率・最短間隔・上限は実装前に定数として決め、テストで固定します。初回カードと失敗カードには別のルールを適用します。評価時はサーバー時刻を基準に `due_at` を計算し、同じレビューイベントを二度適用しません。

## 学習画面の状態

`question`（英単語・英単語音声）→ `answer`（訳・例文・例文音声・各評価の次回間隔）→ `rated`（次カード）の順です。残りのカードがすべて分単位の再試行待ちの場合は、待ち時間が経過していなくても次のカードを表示できます。音声は各再生操作時にWeb Speech APIへ渡してブラウザ内で読み上げます。ブラウザが読み上げに対応していない、または端末に適切な音声がない場合でも、テキスト表示と評価操作を妨げません。解答表示前に日本語訳や例文をDOMに出さない制約も維持します。
