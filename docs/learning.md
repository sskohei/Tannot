# 学習アルゴリズム

FSRS（Free Spaced Repetition Scheduler）を使った間隔反復を採用します。カードごとのレビュー履歴に、次回日時だけでなく FSRS の `stability`、`difficulty`、カード状態、学習ステップ数、忘却回数を保存します。

## 評価

| UI | 意味 |
| --- | --- | --- |
| もう一度 | 想起できなかった。再学習ステップへ戻す |
| 難しい | 苦労して想起 |
| 普通 | 妥当に想起 |
| 簡単 | 余裕を持って想起 |

FSRS の初期設定は目標想起率90%、最大間隔365日、ファジングなしです。短期学習・再学習ステップは10分とし、レビュー履歴が蓄積した後にユーザーごとのパラメータ最適化を追加できる構成にします。評価時はサーバー時刻を基準に `due_at` を計算し、同じレビューイベントを二度適用しません。

既存のレビュー行はFSRS状態がNULLのまま保持され、次回レビュー時にFSRS上の新規カードとして扱われます。過去のレビュー履歴は削除しません。

## 学習画面の状態

`question`（英単語・英単語音声）→ `answer`（訳・例文・例文音声・各評価の次回間隔）→ `rated`（次カード）の順です。残りのカードがすべて分単位の再試行待ちの場合は、待ち時間が経過していなくても次のカードを表示できます。音声は各再生操作時にWeb Speech APIへ渡してブラウザ内で読み上げます。ブラウザが読み上げに対応していない、または端末に適切な音声がない場合でも、テキスト表示と評価操作を妨げません。解答表示前に日本語訳や例文をDOMに出さない制約も維持します。
