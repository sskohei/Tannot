# 正式リリースチェックリスト

コードだけでは完了できない実機、外部サービス、法務・運用の確認を正式リリース前に行います。確認者と確認日をPRやリリース記録へ残します。

## スマートフォン・ブラウザ

- [ ] iPhone SafariでGoogleログイン、単語帳作成、カード編集・削除、音声、復習を確認する。
- [ ] Android Chromeで同じ操作を確認する。
- [ ] Apple Pay対応端末のSafariでStripe CheckoutにApple Payが表示される。
- [ ] Google Pay対応端末のChromeでStripe CheckoutにGoogle Payが表示される。
- [ ] 320px幅でヘッダー、フォーム、カード、料金・法務ページに横スクロールが発生しない。
- [ ] キーボードだけでナビゲーション、フォーム、編集、削除確認、復習評価を操作できる。
- [ ] 200%拡大でも情報や操作が欠けない。
- [ ] 音声読み上げ非対応または拒否時も、テキストで学習を継続できる。

## Stripeテストモード

- [ ] Product / Priceがプレミアム月額500円（税込）として設定されている。
- [ ] 動的決済手段でカード、Apple Pay、Google Payを有効にし、必要なドメインを登録する。
- [ ] Customer Portalで支払い方法更新、請求書閲覧、期間末解約を有効にする。
- [ ] Stripeの顧客メールで、支払い成功の領収書と支払い失敗通知を有効にする。
- [ ] Checkout完了、トライアル開始・終了、更新成功、支払い失敗、追加認証、解約をテストする。
- [ ] Webhook endpointへ必要なイベントを登録し、署名検証と再送時の冪等性を確認する。
- [ ] 本番・ステージング・ローカルでAPIキーとWebhook署名シークレットを共有していない。
- [ ] 本番では用途を確認した最小権限のRestricted API Keyとアクセス制限を検討する。
- [ ] 日本国外への販売予定と税務上の登録要否を専門家へ確認する。登録方針が決まるまで、Stripe Taxの`automatic_tax`を見切りで有効化しない。

## 法務・サポート

- [ ] 利用規約、プライバシーポリシー、特定商取引法に基づく表記を専門家が確認する。
- [ ] 施行日、版、料金、無料期間、自動更新、解約期限、返金条件がStripeの設定と一致する。
- [ ] 所在地・電話番号の開示請求へ遅滞なく対応できる手順を用意する。
- [ ] 問い合わせメールを受信でき、平日10:00〜17:00・3営業日以内の回答体制を確認する。
- [ ] 障害、価格変更、規約変更をアプリ内または登録メールへ通知できる手段を決める。
